# 5～8 号动作组：7、8 号单步加幅实测版

5、6 号仍是从原 0、1 号仅调整时间的快速动作。7、8 号按用户要求改为单步加幅版：保留原帧数和顺序，调整转步腿的部分髋、膝目标，相对 P500 的偏移约增加 15%，不放大踝部侧倾，末帧仍回到六个舵机 P500。为避免更大行程同时提高指令速度，相关帧略延长，本版总时间略长于原 3、4 号的 600 ms。

这是待上机验证的调参版本。15% 指所选舵机相对中位的目标偏移，不是测得的机器人转角增幅；实际转角、落脚和晃动需实测。

## 舵机编号与单步加幅

依据用户提供的背面标注照片：机器人自身左腿由上到下为 6、5、4，右腿为 3、2、1。按照片中安装轴向推断，3/6 为髋部前后摆动，2/5 为膝部，1/4 为踝部侧倾；该判断尚未通过逐舵机点动核验。本机结构没有从照片可确认的独立竖直轴转向关节，因此本次沿用原转步轨迹，只小幅增加参与转步的髋、膝摆动，作为增大单步转角的实测方案。

## 时间调整依据

- 前进：第一帧由 150 ms 增至 160 ms，为从立正姿态启动留出时间；第四、第八帧保持 120 ms，其他阶段小幅缩短。
- 左转：原快速版 220、190、140 ms 改为 255、220、165 ms，为加大的摆动及回正行程留出时间。
- 右转：原快速版 110、150、120、180 ms 改为 110、175、140、210 ms，给更大的膝部摆动和回正留出时间。
- 对比加幅前的 7、8 号，从 P500 起步计算，各帧每个舵机的“目标差值/帧时间”均未增加。这是指令层面的平均行程速度核对，不是负载下的速度或稳定性保证。
- 立正：仍为六个舵机回到 P500，时间改为 800 ms。

LX-824 官方标称速度为 0.20 秒/60°（7.4 V），位置 0～1000 对应 0～240°。这些数据只用于筛查明显过短的时间，不是负载下的完成时间或站稳保证。

## 下载与实测

1. 在原动作编辑软件下载界面分别打开四份 XML，明确选择下载到动作组 5、6、7、8；保留原 0、1、3、4 组便于比较。文件名不会自动决定主板存储槽位，XML 内的 `<ID>` 是帧编号，不能改成动作组号。
2. 先单独运行每个新动作。6 号前进分别检查从立正启动和连续周期；7、8 号从立正启动，分别与备份版比较实际转角、回正和落脚。若幅度没有增加或晃动加大，恢复备份，再依据实测逐项调整。
3. 再检查前进与转向的衔接。若落脚不稳或动作未到位，增加对应帧时间或恢复原组，不继续压缩动作后的站稳等待。

## 循线程序接入

`main.py` 已采用两档转向：直线偏移时使用原 3、4 号；三框均为干净的实际观测，且近远中心横差大于 14 像素，或中点偏离近远连线大于 8 像素时，使用加幅 7、8 号。仅有整体横向偏移不会触发加幅；缺框、横线污染或窄带重检时使用原转向。方向和幅度须一起满足原有连续帧数与持续时间确认后才发令。

主板需保留 0=立正、1=前进、3/4=原左/右转，并将最新两份加幅 XML 下载到 7、8 号。仅把 XML 放进本机目录不会更新主板。5、6 号快速立正、前进尚未接入本程序，9、10 号落地停稳版也未接入。

当前 3、4 号各保留 750 ms 保守计时；7、8 号按新文件分别计时 640、635 ms，再加当前 `TURN_SETTLE_MS=150` ms 后才允许下一动作。转向对正后先前进的恢复逻辑适用于两档转向；`REVERSE_TURNS` 也同时交换两档的左右方向。画面及串口输出中的 `LEFT_LARGE`、`RIGHT_LARGE` 表示加幅动作。

如果后续调整了 XML 时间，应同步调整程序计时，不要继续沿用旧快速版的 550、560 ms。原始方向判断仍先使用 3、4，再按线形选择 7、8；7 是加幅左转，不是前进一步。
